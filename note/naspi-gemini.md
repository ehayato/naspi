# 🏠 自宅データサーバー・バックアップ構成定義書

先輩専用の「手軽さ」と「鉄壁の守り」を両立したシステム構成案。

## 🛠 ハードウェア構成
- **1TB SSD (2.5インチ)**: メイン作業領域・クラウド同期用
- **4TB HDD (3.5インチ / exFAT)**: 世代管理バックアップ・アーカイブ用
- **ホストOS**: Linux (Arch Linux / Raspberry Pi OS等)

## 🐳 Docker サービス構成
SSDをマウントし、以下のコンテナを連携させる。

### 1. Immich (フォト管理)
- **役割**: Googleフォト代替のUI提供。
- **データ保存先**: SSD。AI検索や顔認識を活用。
- **特徴**: 公開時はCloudflare Tunnel経由で安全に閲覧。

### 2. Samba (ファイル共有)
- **役割**: ノートPCからSSDへの高速アクセス。
- **設定**: LAN内限定。特定のディレクトリをネットワークドライブとして公開。

### 3. rclone-sync (クラウド同期)
- **役割**: 1時間おきに SSD ↔ Proton Drive (Fileタブ) を同期。
- **運用**: クラウドをマスターとし、常に最新状態を維持。

### 4. restic-backup (世代管理)
- **役割**: 深夜にHDDをマウントし、SSDの内容を暗号化バックアップ。
- **ポリシー**: 日次7日間 + 週次4週間の世代管理。
- **運用**: スクリプト実行時のみHDDをマウントする「noauto」運用。

### 5. Discord Bot (司令塔)
- **役割**: 手動同期(`!sync`)、手動バックアップ(`!backup`)、状態確認(`!status`)の受付。
- **連携**: Docker Socketをマウントし、他コンテナを操作。

## 🔒 セキュリティ & ネットワーク
- **外部アクセス**: Cloudflare Tunnel (or Tailscale)。
- **認証**: 2FA (二要素認証) を全ての入口に適用。
- **暗号化**: ResticによるHDD内の軍事級暗号化 (AES-256)。
- **VPN共存**: ProtonVPNのスプリットトンネリング設定で外部アクセスを確保。

## 📅 運用スケジュール
| 時間          | タスク          | 内容                                                         |
| :------------ | :-------------- | :----------------------------------------------------------- |
| **1時間毎**   | `rclone sync`   | クラウドとの最新差分を埋める                                 |
| **深夜3~5時** | `restic backup` | HDDマウント ➔ 重複排除バックアップ ➔ 世代整理 ➔ アンマウント |
| **随時**      | Discord操作     | メンテ時や急ぎの同期をBot経由で実行                          |

---
**注意**: Resticのリポジトリパスワードは、必ずProton Pass等の安全な場所に保管すること！
